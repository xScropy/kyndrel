## Bugs this found
- **A dropped stream or truncated file counted as "watched".** mpv reports
  it as a normal end of file once it gives up, so the resume point was
  cleared, history marked it finished and the queue moved on. An end of
  file more than max(5 s, 3 %) before the known duration is now an error
  (`PlaybackState.endedEarly`); the error screen says what happened and
  the resume point is kept.
- **A dropped stream showed a spinner for about two minutes.** FFmpeg's
  reconnect backoff (0, 1, 3, 7, 15, 31, 63 s) is now capped at 15 s, so it
  gives up after ~26 s (`stream-lavf-o=reconnect_delay_max=15`).

## Not covered here
- **Real HDR output** (tone mapping on an HDR display, or to SDR): needs a
  GPU and an HDR screen. The tone-mapping choice from Settings is passed
  through (`tone-mapping`, task 4.7); check it by eye on real hardware.
- **4K AV1 / HEVC with hardware decoding**: no GPU here; CPU decoding of
  4K30 H.264 keeps up (see `docs/performance.md`).
- Dolby Vision, HLG and 12-bit sources.
